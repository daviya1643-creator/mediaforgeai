# mediaforgeai
A cutting-edge multimedia workflow platform powered by AI. Generate, edit, and automate video and image processing directly in the browser using Transformers.js and ONNX Runtime

## Adobe Premiere Pro handoff

MediaForge AI can export a Final Cut Pro 7 XML interchange sequence from the Export & Share screen. Import the XML in Premiere Pro, relink browser-uploaded media if prompted, and save the imported sequence as a native `.prproj` project. The XML contains edit metadata; it does not bundle media.

See [Premiere Pro XML export](docs/premiere-pro-export.md) for import, relinking, and caption instructions.
